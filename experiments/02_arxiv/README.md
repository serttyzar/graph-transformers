# ogbn-arxiv · как точно модели определяют тему статьи

В одном графе 169 343 научные публикации. Требуется отнести каждую к одному из 40 классов. Все модели видят связи и признаки графа. Обучение использует метки обучающих вершин, проверочная выборка определяет эпоху, тестовая даёт итоговую точность.

| Где открыть | На что обратить внимание |
|---|---|
| [E4_arxiv.yaml](E4_arxiv.yaml) | У всех трёх вариантов одинаковые номера запусков. В секции `variants` перечислены глубина, ширина и настройки каждого варианта. |
| [data.py](../../src/gt/data.py) и [run.py](../../src/scripts/run.py) | `load_ogbn_arxiv` читает граф и официальное разбиение. В `run_arxiv_experiment` добавляются обратные рёбра, создаётся модель и вычисляется итоговая метрика. |
| [models_node.py](../../src/gt/models_node.py) | `GCN` обновляет признаки по рёбрам. `SGFormerLike` объединяет GCN с линейным вниманием. `hop_features` готовит для `NAGphormerLike` восемь векторов на статью — исходный и семь результатов распространения. |
| [train.py](../../src/gt/train.py) | `train_node_level` выбирает веса по проверочной точности. Функция `evaluate_node` считает качество на заданном наборе вершин. |

**Что получилось.** GCN правильно классифицировала 71,79 % тестовых публикаций, SGFormer-подобная модель — 71,34 %, NAGphormer-подобная — 71,55 %. В среднем последняя ближе к GCN, но разброс у неё больше. Верхняя граница интервала потери точности составила 1,026 процентного пункта для NAGphormer-подобной модели и 0,735 для SGFormer-подобной при допуске в один пункт.
