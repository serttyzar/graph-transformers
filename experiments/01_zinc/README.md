# ZINC · как связи между атомами влияют на ошибку

Для каждой молекулы нужно предсказать одно число — свойство из набора ZINC. Все варианты получали типы атомов. Восемь моделей обучались на одном разбиении с начальными значениями генератора 0, 1 и 2. Метрика MAE показывает средний модуль ошибки на молекулу. Меньше — лучше.

| Где открыть | На что обратить внимание |
|---|---|
| [E1_zinc.yaml](E1_zinc.yaml) | В разделе `base` заданы общие параметры. В `variants` видно, что отличает восемь вариантов. У `gt-rwse` и `gt-neigh-rwse` совпадает RWSE, у второго включена маска `neighbors`. |
| [encodings.py](../../src/gt/encodings.py) и [pair_encodings.py](../../src/gt/pair_encodings.py) | `laplacian_pe` и `random_walk_se` описывают вершину. `shortest_path_dense` и `rrwp_dense` вычисляют признаки пар. |
| [models.py](../../src/gt/models.py) | `GraphTransformer.attention_inputs` строит поправку для пары и маску соседей. `fit_budget` подбирает ширину под бюджет параметров. |
| [layers.py](../../src/gt/layers.py) | `DenseAttention.forward` применяет маску перед нормировкой весов. В `GPSLayer` видны локальная ветвь и полное внимание. |
| [run.py](../../src/scripts/run.py) и [train.py](../../src/gt/train.py) | `run_graph_experiment` выбирает модель и данные. `train_graph_level` сохраняет веса с наименьшей проверочной MAE, затем оценивает их на тестовых молекулах. |

**Что получилось.** У полного трансформера с RWSE средняя тестовая MAE составила 0,2647. После ограничения внимания самим атомом и его соседями она снизилась до 0,1329. В обоих вариантах по 510 873 параметра. Гибрид GPS дал 0,1532, локальная сеть GIN — 0,1766. Плотная реализация маски в этом опыте проверяла, как ограничение связей влияет на качество.
