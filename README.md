# Представление структуры графа в графовых трансформерах

Как передать трансформеру сведения о рёбрах и сколько стоит обработка большого графа? Первая серия проверяет качество на молекулах, вторая — на графе публикаций. В третьей меняется размер графа и измеряются вычислительные затраты.

| Серия | Что показать в коде | Где смотреть результат |
|---|---|---|
| [1. ZINC](experiments/01_zinc/README.md) · раздел 5.1 РПЗ | Четыре кодировки, маска внимания и сравнение GPS с GIN | [24 обучения](experiments/01_zinc/runs.csv) · [ошибка восьми моделей](experiments/01_zinc/zinc_scores.png) |
| [2. ogbn-arxiv](experiments/02_arxiv/README.md) · раздел 5.2 | GCN, линейное внимание и обработка окружения вершины | [9 обучений](experiments/02_arxiv/runs.csv) · [точность трёх моделей](experiments/02_arxiv/arxiv_scores.png) |
| [3. Масштабирование](experiments/03_scaling/README.md) · раздел 5.4 | Один прямой и обратный проход при увеличении графа | [90 записей](experiments/03_scaling/runs.csv) · [время](experiments/03_scaling/scaling_time.png) · [память](experiments/03_scaling/scaling_memory.png) |

**Для показа на защите** откройте первый раздел, затем функцию `GraphTransformer.attention_inputs` и сравните строки `gt-rwse` и `gt-neigh-rwse`. Код показывает, где меняется маска, таблица — что это дало при одинаковой кодировке и числе параметров. В каждом разделе есть такой же маршрут от вопроса к числам.

Готовые результаты можно посмотреть и в терминале. Из корня репозитория выполните:

```sh
python3 show_results.py
```

Команда читает три сохранённые таблицы с диска. Достаточно стандартного Python 3. Для просмотра вручную откройте CSV и PNG в папках серий.

## Откуда взялись код и числа

- В каждой папке эксперимента лежит исходный YAML. Реализация моделей и точки входа общие. Файлы в [src/gt](src/gt) и [src/scripts](src/scripts) побайтно соответствуют одноимённым файлам снимка, на котором выполнена основная серия. Идентификатор полного снимка по SHA-256 — `53cdb67277e393cb`. В него при вычислении хэша входили также служебные скрипты полного проекта. В этом репозитории собраны файлы трёх показанных серий.
- В каждой папке `records.jsonl` содержит научные поля исходных записей, одна строка на запуск. В обучающих сериях сохранены в том числе проверочное качество по эпохам, лучшая эпоха и тестовая оценка для выбранных весов. В разделе 5.3 РПЗ используются [парные сравнения ZINC](experiments/01_zinc/comparisons.csv) и [ogbn-arxiv](experiments/02_arxiv/comparisons.csv). [Функции обработки](analysis/metrics.py) перенесены из скриптов, которыми рассчитаны таблицы.
- Эксперименты выполнены с Python 3.12, PyTorch 2.8.0a0+5228986c39.nv25.05, PyG 2.6.1 и CUDA 12.9 на H100. Два обучения использовали [базовый цикл](src/gt/train.py), остальные 31 — [вариант с сохранением состояния](src/recovery/resumable_train.py) из версии дополнения `f5e270a0310c6ea7`. В таблицах `runs.csv` поле `recovered` отмечает фактическое продолжение с сохранённой эпохи.
